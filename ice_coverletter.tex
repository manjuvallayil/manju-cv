\vspace{4pt}

\begin{tcolorbox}[

\begin{itemize}

  \item \textbf{Clinical data, firsthand.}
        As a Research Assistant at AUT, I applied machine learning to EEG, psychological, and
        clinical datasets in a tinnitus detection project. The work required preprocessing
        heterogeneous data, resolving inconsistencies across sources, and keeping clear
        records of processing choices and outcomes throughout.

  \item \textbf{Precision built through QA.}
        Before research, I spent several years as a Software Quality Assurance Engineer
        performing SQL-based backend data validation, writing test case documentation, and
        verifying data integrity on live systems. That background made systematic accuracy
        checks second nature, not an afterthought.

  \item \textbf{Contribution to clinical EEG tooling.}
        During the tinnitus project I contributed a pull request to
        \href{https://github.com/ufvceiec/EEGRAPH}{EEGRAPH}, an open-source EEG processing
        library used in clinical research. The PR was reviewed and merged by the project
        maintainers. Getting a contribution accepted into clinical research tooling required
        understanding the underlying data structures and processing patterns well enough to
        meet the standards of researchers actively working in the field.

\end{itemize}
\end{tcolorbox}
